# My Medical History

### A Flutter-Based Personal Medical Record Management Application

**My Medical History** is an Android application developed using Flutter and Dart. It helps users organize, manage, and access their personal medical information in one place.

The application provides a simple interface for managing doctors, medical visits, prescribed medicines, medical tests, and visit history. It uses Google Sign-In for authentication and an encrypted local SQLite database for account-specific medical records.

The project also includes Google Drive backup and restore functionality designed to protect exported records with a recovery password.

## Project Objectives

- Provide a digital solution for organizing personal medical records.
- Make doctor and medical visit information easy to access.
- Store medical records locally using encryption.
- Keep each Google account's records separate.
- Support encrypted Google Drive backups and recovery.
- Create a simple, user-friendly Android application.

## Main Features

### 1. Google Sign-In

Users can sign in using their Google account. The application provides account-based access without requiring a separate registration form.

### 2. Dashboard

The dashboard provides access to the main sections of the application, including medical history, doctors, visits, and other records.

### 3. Doctor Management

Users can manage doctor information and associate doctors with medical visits.

### 4. Medical Visit Management

The application provides a step-by-step medical visit form for entering and organizing visit-related information.

### 5. Medical History

Users can view their saved medical visits and related medical information in an organized format.

### 6. Medicines and Medical Tests

The application supports storing prescribed medicine information and medical test details associated with visits.

### 7. Encrypted Local Storage

Medical information is stored in an account-specific SQLite database using SQLCipher encryption.

### 8. Google Drive Backup and Restore

The application includes functionality for creating password-encrypted medical record backups and restoring supported records from private Google Drive application storage.
